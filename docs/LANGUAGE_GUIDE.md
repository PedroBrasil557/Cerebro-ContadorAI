# Guia de linguagem

## Princípios

- escrever em português brasileiro simples, direto e respeitoso;
- diferenciar fato observado, estimativa, hipótese e recomendação;
- dizer “dados insuficientes” ou “não configurado” em vez de inventar zero;
- evitar promessas de resultado, precisão absoluta ou aconselhamento tributário definitivo;
- usar “Cérebro.IA Pessoal” e “Cérebro.IA Profissional” para os produtos.

## Vocabulário preferido

| Evitar | Preferir |
| --- | --- |
| neural, cognitivo, protocolo, comando | análise, recurso, processo, orientação |
| sala de guerra | plano de quitação |
| CFO virtual, conselho | análise do negócio |
| lucro limpo no bolso | resultado estimado |
| cliente perdida, padrão ouro | sem contato recente, margem estimada |
| risco crítico sem base | dados insuficientes ou indicador observado |

“IA” só aparece quando há uma chamada real ao provedor. Cálculos locais devem ser descritos como regras, simuladores ou estimativas.
