# Brand & Merchant Iconography

Local recognition assets used by the Cérebro.IA merchant/app identity layer.

- Integration is presentation-only: transaction data and financial contracts are not changed.
- Known merchants resolve through `core/brand/merchantBrandRegistry.ts`.
- Unknown merchants use the controlled category + monogram fallback from `MerchantBrandAvatar`.
- Product/navigation actions continue to use Lucide; brand marks are only for merchant/app identity.
- The normalized SVG shapes in this initial set are sourced from Simple Icons and are stored locally so production does not depend on a third-party icon CDN.
- Brand names and marks remain the property of their respective trademark holders and are used for identification only.

Initial persisted set: Nubank, PayPal, Visa, Mastercard, Shopee, iFood, Uber, Spotify, Netflix, YouTube, GitHub, Discord and Steam.
